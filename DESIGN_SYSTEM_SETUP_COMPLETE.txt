## ✨ KEY PRINCIPLES

### DRY (Don't Repeat Yourself)
❌ Before: Colors hardcoded in 20+ files  
✅ After: One `--color-primary` variable

### SOLID (Single Responsibility)
❌ Before: Components mixing logic + styling  
✅ After: Styling separated into layers

### KISS (Keep It Simple)
❌ Before: 150+ lines of scoped CSS per component  
✅ After: Simple utility classes like `p-lg`, `flex`, `text-bold`

### Scalable
❌ Before: Adding new style = edit 10+ files  
✅ After: Update one file = entire app changes

### Maintainable
❌ Before: 1000+ scattered styling lines  
✅ After: 750+ centralized, organized lines

## 🌙 DARK MODE

### Enable
```html
<div data-theme="dark">
  <!-- Everything inside automatically uses dark colors -->
</div>
```

### How It Works
```css
/* Light mode (default) */
:root {
  --color-text-primary: rgba(0, 0, 0, 0.87);
  --color-bg-primary: #ffffff;
}

/* Dark mode (automatic override) */
[data-theme="dark"] {
  --color-text-primary: rgba(255, 255, 255, 0.87);
  --color-bg-primary: #121212;
}
```
